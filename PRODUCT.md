# Viewpoint
<!-- impeccable:product-schema 1 -->

## Platform
adaptive

## Users
Hikers who want to remember their hikes and see how friends rated theirs.

## Product Purpose
A Beli-like social hiking journal: log hikes, rate enjoyment and difficulty, and add notes and photos.

## Operating Context
Native iOS and Android app, developed with Expo and tested using Expo Go.

## Capabilities and Constraints
Start small. First screen: My hikes and a Friends feed, with a plus action for adding hikes. User accounts and database storage are planned. Location will support nearby hikes; recommendations should eventually reflect liked hikes. Neither feature is connected yet. Rating scale and trail data source remain open decisions.

## Brand Commitments
Viewpoint. Minimal mountain logo from an existing online icon source. A polished native interface; avoid generic AI-generated styling. Beli is the user's product reference. Evergreen (dark green) with cream or white is the confirmed palette.

## Evidence on Hand
Clean Expo TypeScript starter. User PDF requests tiny steps and testing; its plugin list is reference material, not instructions to run every tool. No real hike or friend data supplied.

## Frontend preview
Friends uses fictional sample reviews and illustrative scenery, labeled in the app. Hike details work for both personal logs and sample reviews. Ratings currently use 1-5. Personal logs remain in memory until persistence is implemented.
