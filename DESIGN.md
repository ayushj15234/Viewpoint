# Viewpoint design

Native app screen, operate mode. Follow the user's Beli reference with restrained social-list conventions: system typography, flat content rows, white-green surfaces, and a single forest-green action color. No invented friend activity or decorative metrics.

Tokens: background #FAFBF8; ink #1F2B24; secondary #626B64; action #245B45; divider #CFD5CE. Main spacing 24, control minimum 48, input radius 10, button radius 12. Screen titles 34/700; body 16–17. Typography scales with system settings.

Use safe-area insets and a keyboard-aware sheet for logging. Two content tabs; the plus is an action, never a navigation destination. The initial mountain mark comes from the Font Awesome 5 icon set bundled through Expo vector icons. Launcher assets are still Expo defaults.

Current scope: My hikes list, Friends empty state, and temporary session logging. Light appearance matches app.json. Native visual verification is pending a phone or emulator.
