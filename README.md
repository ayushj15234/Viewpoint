# Viewpoint

Viewpoint is a mobile app built with React Native and Expo.

## Get started

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. In this folder, install the project dependencies:

   ```bash
   npm install
   ```

3. Start the Expo development server:

   ```bash
   npx expo start
   ```

4. Install **Expo Go** on your phone and scan the QR code shown in the terminal. Your phone and computer should be on the same Wi-Fi network.

Edit `App.tsx` to start building the app. The existing `LICENSE` file is unchanged.
